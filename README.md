# Hack01: Physical AI Humanoid Robotics Textbook with Chatbot

This project is an AI-powered interactive platform for learning about Physical AI and Humanoid Robotics. It integrates a RAG (Retrieval-Augmented Generation) chatbot with educational content to provide a seamless learning experience.

## Features

- **RAG Chatbot:** Intelligent chatbot capable of answering questions based on the provided robotics textbook content.
- **Content Retrieval Pipeline:** Automated pipeline for crawling, chunking, and embedding documentation.
- **Vector Database:** Utilizes Qdrant for efficient vector storage and retrieval.
- **Interactive Frontend:** Built with Docusaurus to present the textbook and interact with the chatbot.

## Project Structure

- `backend/`: Python-based backend handling the RAG pipeline, embedding service, and API endpoints.
- `frontend/`: Docusaurus-based documentation and web interface.
- `specs/`: Detailed project specifications and documentation.
